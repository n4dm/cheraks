# Security Policy

## Project status

Cheraks is an experimental blockchain prototype, not a production cryptocurrency. It has not undergone an independent security audit. Do not use it to store or transfer real funds.

## Reporting a vulnerability

Please do not publish exploit details for a potentially serious vulnerability in a public issue before maintainers have had a chance to assess it.

Use GitHub's private vulnerability reporting for this repository if that feature is enabled. If private reporting is unavailable, contact the repository maintainers through GitHub to arrange a private disclosure. Include:
- the affected file, component, or commit;
- steps to reproduce the issue;
- the impact you believe is possible;
- any proof of concept that can be shared safely.

Do not include real secrets, private keys, or personal data in reports.

## Scope

Relevant reports include block-validation failures, hash or serialization ambiguities, invalid reward acceptance, state corruption, denial-of-service risks, unsafe file handling, and issues that could cause nodes to disagree on valid chain state.

This policy does not promise a response time, bounty, or service-level agreement.
